# 客户项目实施指南 / Customer Project Playbook

## 项目阶段 / Project Stages

标准客户项目分为四个阶段：

1. 需求分析：一周
2. 数据准备与系统配置：三周
3. 试点和用户验收测试：三周
4. 上线与培训：两周

A standard customer project has four stages:

1. Requirements discovery: one week
2. Data preparation and system configuration: three weeks
3. Pilot and user acceptance testing: three weeks
4. Launch and training: two weeks

标准项目的计划总周期为九周。任何范围变更都必须记录在变更申请中，并由客户项目负责人和公司项目经理共同批准。

The planned duration of a standard project is nine weeks. Any scope change must be documented in a change request and approved by both the customer's project owner and the company's project manager.

## 客户数据 / Customer Data

项目团队只应收集实施所必需的数据。敏感数据必须使用批准的加密渠道传输，并存储在项目指定的位置。除非合同另有规定，项目结束后 30 天内应删除临时数据副本。

Project teams should collect only data required for implementation. Sensitive data must be transferred through approved encrypted channels and stored in the designated project location. Unless the contract states otherwise, temporary data copies must be deleted within 30 days after project completion.

## 上线标准 / Launch Criteria

系统上线前必须满足以下条件：关键用户验收测试全部通过、没有未解决的严重缺陷、操作手册已交付，并且至少两名客户管理员已完成培训。

Before launch, all critical user acceptance tests must pass, no severe defects may remain open, the operating guide must be delivered, and at least two customer administrators must complete training.

## 问题升级 / Escalation

严重问题应立即通知项目经理和技术负责人。若问题影响客户生产，项目经理必须在 30 分钟内建立响应群组，并每小时向客户提供一次进展更新。

Critical issues must be reported immediately to the project manager and technical lead. If an issue affects customer production, the project manager must create a response group within 30 minutes and provide hourly progress updates to the customer.
